The switch-on reveal

The one big moment a page gets. The piece is seen off, then the light comes up the way a real LED driver settles: dark amber first, then warm white. Used once per page, on the hero or the first product image, when it scrolls into view.

Duration
900 ms, after a 450 ms hold
Easing
power2.out
Trigger
Scrolls into view, once. Replay on tap.
Where
Hero, first gallery image, the 3D viewer
gsap.timeline({ scrollTrigger: { trigger: el, start: "top 75%", once: true } })
  .to(onImg, { opacity: 1, duration: 0.9, ease: "power2.out" }, 0.45)
  .fromTo(onImg, { filter: "brightness(.55) saturate(1.4)" },
                 { filter: "brightness(1) saturate(1)", duration: 0.9, ease: "power2.out" }, 0.45);

3

Sections arrive, quietly

As you scroll, a section's content rises 8 px and fades in, once. It reads as a fade, not a slide. Cards stagger by 60 ms so a row feels placed, not dropped. Everything is visible without scrolling if scripts fail.

Duration
350 ms, stagger 60 ms
Easing
power1.out
Trigger
Section top reaches 88% of the viewport, once
Where
Every section below the fold. Never the hero.
gsap.from(section.children, { opacity: 0, y: 8, duration: 0.35, stagger: 0.06,
  ease: "power1.out", scrollTrigger: { trigger: section, start: "top 88%", once: true } });

4

Cards switch on under your hand

Every product card carries the piece off and on. Hover on a desktop, or tap on a phone, and the light comes up. The card itself does not lift, tilt or grow. The product moves; the chrome stays still.

Duration
240 ms in, 320 ms out
Easing
power1.out
Trigger
Hover, focus, or tap
Where
Product cards on home, collections, related items
card.addEventListener("pointerenter", () => gsap.to(onImg, { opacity: 1, duration: 0.24, ease: "power1.out" }));
card.addEventListener("pointerleave", () => gsap.to(onImg, { opacity: 0, duration: 0.32, ease: "power1.out" }));

Controls respond, then stop

The sticky buy bar slides up once the real button has scrolled away, and slides back down when it returns. An answer in the FAQ opens by growing, not by popping. Both are state changes made visible, and both are done in under a quarter of a second.

Duration
240 ms
Easing
power2.out
Trigger
Button leaves the viewport; question tapped
Where
Sticky bar, FAQ, cart drawer, toasts
// sticky bar
new IntersectionObserver(([e]) => gsap.to(bar, { yPercent: e.isIntersecting ? 110 : 0,
  duration: 0.24, ease: "power2.out" })).observe(buyButton);
// accordion
gsap.from(answer, { height: 0, opacity: 0, duration: 0.24, ease: "power2.out", clearProps: "height" });

What a NixWoods page never does

These are common on other stores and in the reel you sent. Each one moves while someone is trying to read or decide, or makes the page feel like it is selling harder than the product needs.

  • Parallax and scroll-jacking (Lenis-style smooth scroll)
  • Marquees and auto-playing text carousels
  • Countdown timers and "selling fast" pulses
  • Cards that lift, tilt or grow on hover
  • Bounce, spring or elastic easing
  • Pinned sections that scrub with the scrollbar
  • Confetti, sparkles, cursor trails
  • Text that types itself or splits by letter
  • Anything that autoplays with sound
  • Entrance animations on the hero
