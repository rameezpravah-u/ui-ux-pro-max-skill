## E. How to apply (when approved)

1. Duplicate the live theme in Shopify admin; name it "NixWoods week1 YYYY-MM-DD".
2. Apply A and B in the theme editor or by uploading the edited JSON to the duplicate.
3. Apply C in Judge.me and Navigation. C2 and C3 take effect on the live theme immediately; C2 is harmless (metafields only), C3 is a visible nav change and is part of the approval.
4. Preview the duplicate; run `qa/shots.sh week1-preview` against the preview URL (edit `BASE` in the script for the run).
5. Show before and after to Rameez. Publish on yes. Run `qa/shots.sh week1-live`.
